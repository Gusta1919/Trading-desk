Folder: ~/Documents/Trading/trade-assistant/

PIERWSZY RAZ:
  1. Zainstaluj Node.js → nodejs.org (LTS)
  2. Terminal (pobranie z GitHuba):
       cd ~/Documents/Trading
       gh repo clone Gusta1919/Trading-desk trade-assistant
       cd trade-assistant
       npm install

AKTUALIZACJA DO NOWEJ WERSJI (z GitHuba):
  Zamknij dziennik (okno Terminala z serwerem), potem w Terminalu:
       cd ~/Documents/Trading/trade-assistant
       git fetch origin
       git checkout main
       git pull
       npm install
  Potem uruchom jak zwykle. Przy pierwszym starcie dziennik sam się czyści
  (patrz ŚWIEŻY START niżej).

KAŻDY RAZ — wybierz jedną opcję:

  A) APLIKACJA W DOCKU
     Kliknij dwukrotnie → Trade Assistant.app
     Po ~10 s otwiera się przeglądarka z dziennikiem.

  B) TERMINAL (najpewniejsze, widać co się dzieje)
     Kliknij dwukrotnie → Start Trade Assistant.command
     Zostaw okno otwarte — zamknięcie = wyłączenie serwera.

  C) PRZEGLĄDARKA JAK APLIKACJA (po uruchomieniu serwera)
     Chrome: ⋮ → Zapisz i udostępnij → Zainstaluj stronę jako aplikację…
     Safari: Plik → Dodaj do Docka…

  D) TERMINAL ręcznie
     cd ~/Documents/Trading/trade-assistant && npm start
     Potem: http://localhost:3847

GDZIE SĄ MOJE DANE:
  data/trade-assistant.db  — jeden plik SQLite: transakcje, check-iny i rulebook
  (każda wersja). Zapisuje się natychmiast po zapisaniu transakcji / check-inu.
  Zamknięcie przeglądarki, serwera albo Maca niczego nie kasuje.

  KOPIA ZAPASOWA — dwa sposoby:
   1. Ikona pobierania (↓) w górnym pasku → plik .json z wszystkim (do Downloads).
   2. Skopiuj cały folder data/ (np. do iCloud / na dysk zewnętrzny).
      Najpierw zamknij serwer, żeby plik był kompletny.

ŚWIEŻY START:
  Pierwsze uruchomienie tej wersji samo przenosi starą bazę do data/archive/
  (nic nie jest kasowane). Dziennik startuje pusty, z rulebookiem GOLD Model
  jako wersją 1.0. Twoje własne check-iny przechodzą do nowej bazy. Wszystko,
  co zostało po starym demo, jest usuwane przy starcie — dziennik jest czysty.

  Później, w dowolnym momencie (najpierw zamknij serwer):
    npm run reset         przenosi bazę do data/archive/ — następny start jest pusty

JAK TO DZIAŁA (w skrócie):
  Serwer (port 3848) czyta i zapisuje bazę, strona (port 3847) ją pokazuje.
  Wszystko działa lokalnie na tym Macu — nic nie wychodzi do internetu.

STARA WERSJA SIĘ OTWIERA?
  To znaczy, że w tle działa stara kopia serwera. Launchery (Start Trade
  Assistant.command i aplikacja w Docku) same ją wykrywają, zatrzymują
  i uruchamiają wersję z tego folderu. Ręcznie:
       lsof -ti tcp:3847 -ti tcp:3848 | xargs kill

GDY NIC SIĘ NIE DZIEJE:
  1. Użyj opcji B (Start Trade Assistant.command) — zawsze pokazuje okno
  2. Pierwszy raz macOS może zapytać o zgodę — kliknij „Otwórz"
  3. Logi: data/launcher.log

SKRÓT KLAWISZOWY (np. ⌘⇧T) — Shortcuts / Skróty:
  1. Dodaj „Uruchom skrypt powłoki" (Run Shell Script)
  2. Wklej:
       export PATH="/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:$PATH"
       bash "$HOME/Documents/Trading/trade-assistant/scripts/launch.sh"
  3. Ustaw powłokę: /bin/bash
  4. ⓘ → Skrót klawiaturowy → np. ⌘⇧T

W APLIKACJI:
  N        — nowa transakcja (najpierw ocena setupu, potem transakcja)
  ⌘↵       — zapisz transakcję
  1–5      — odpowiedzi w porannym check-inie (w weekend nie ma check-inu)
  Today    — prawy dolny róg: status dnia (okna wejść, okna newsów, skip day,
             dzień wolny); najedź myszą, żeby zobaczyć cały dzień, budżety i konto
  ↓        — pobierz kopię wszystkiego: transakcje, check-iny, rulebook z changelogiem
  Rulebook — zasady GOLD Model; każda sekcja edytuje się na miejscu, każda zmiana
             wymaga jednego zdania powodu i trafia do changelogu. Limity konta
             zmieniasz tylko tutaj (sekcja „Limits and consequences").
